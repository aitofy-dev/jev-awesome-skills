# Security

Report a vulnerability privately to hello@aitofy.dev. Please include the package version, the smallest input that shows the issue, and whether a secret was involved.

Do not open a public issue that contains an API key, a proxy credential, or a customer payload. The CLI is written so a live call reads the key from the environment and does not print it. If you find a path that does, that is the report we want.

There is no telemetry in this package.
